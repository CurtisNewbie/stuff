name: queue
description: Queue an instruction to run after the current task finishes
---

Queue the following instruction and carry it out after your current task is completely done.

Rules:
- Confirm the queued instruction to the user in one short line.
- Do not act on it now. Keep it in mind while finishing the current task.
- When the current task is done, apply the queued instruction before ending your turn.
- If the current task is already finished, apply it immediately.
