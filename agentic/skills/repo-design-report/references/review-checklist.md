# 审阅清单：repo-design-report 准确性审阅

供审阅模式维度 B（准确性审阅）使用。写作质量审阅直接复用 `report-template.md` 风格规则与 SKILL.md §7，不在此重复。

## 论断分类表

| 标签 | 含义 | 使用场景 |
|---|---|---|
| ✅ 一致 | 报告论断与当前代码一致 | 默认多数情况 |
| 🔄 已变化 | 报告写的曾经对，代码后来变了 | 字段改名、公式调整、状态机加了新状态 |
| ❌ 从未成立 | 报告本身就错，不是代码变化导致 | 编造的字段、误读的公式 |
| 🆕 未覆盖 | 代码有报告完全没提到的新东西 | 新增实体、新增工作流分支 |
| 🗑️ 应移除 | 报告提到的东西现在是死代码 | 实体/路径已废弃、无活跃引用 |

## 证据可引用标识符

此工件是维护用工作稿，不是最终报告，允许引用字段名、函数名、文件路径，帮维护者快速定位。跟最终报告"无标识符/无文件路径"的规则不同，那条规则只约束最终报告本体。
